# Before You Begin

Make sure you have the following ready before you start:

- **Your platform URL** — <https://searn-lms.titaned.com/>
- **Your login credentials** — the email and password (or invitation link) you received during onboarding.
- **Access to your email inbox** — a one-time passcode (OTP) is emailed to you at every login, so you must be able to open the mailbox for the email address you registered with.
- **A modern web browser** — Google Chrome or Microsoft Edge is recommended.

!!! note "New to the platform?"
    If you received an invitation email, click the link in it to set your password before your first login.
