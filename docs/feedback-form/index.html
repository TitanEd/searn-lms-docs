SEARN NRA LMS Pilot Feedback Form

Structured feedback by user group | For pilot validation and improvement tracking

This form captures practical feedback from each user group participating in the SEARN NRA LMS pilot. The aim is to validate current platform workflows, role fit, usability, access, records, and catalogue. It is not intended to collect broad wishlist items or new scope.

How to Complete the Form

Use the same score scale for each feedback item:

ScoreMeaning
1Not clear / not usable
2Partly clear / needs improvement
3Mostly clear / usable with minor changes
4Clear and useful
5Very clear and directly useful

For comments, please describe the specific issue or improvement. Specific feedback is more useful than general reactions.
