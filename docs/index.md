## Purpose

This guide helps you perform real tasks on the SEARN Capacity Building Platform during the pilot. It is organised by user role. Find your role, then follow the task you want to complete — or use the [Quick How-tos](how-tos.md) page to jump straight to a task.

## How to Use This Guide

Each task follows the same simple pattern, so once you have done one, the rest feel familiar:

- **The story** — one line explaining why you would do this task.
- **Navigation** — where to click to get started.
- **Steps** — a short list of exactly what to do.
- **Outcome** — how you know it worked.
